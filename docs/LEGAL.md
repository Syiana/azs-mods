## The rule

A package listed here must contain only text and files its author may share.

- **No game files.** A package must not contain Blizzard's game files, or anything extracted from
  them: no archives (`.mpq`), no models (`.m2`, `.mdx`, `.wmo`), no textures (`.blp`), no sounds,
  no music, no DBC tables, whole or in part, under any name or file extension.
- **Naming is fine.** A package may name files of the player's own game client by their id or path:
  a spell id, a creature display id, an icon name, a model path, a map id. That is how the game's
  own content works: the player's client already holds those files, and the package carries none.
- **Your own files.** Pictures, sounds and texts that the author made, or may share under their
  licence, may ship in a package. The package's `LICENSE` says which files it covers; the game's
  own packs that a profile carries are the game's, not the author's.
- **Consequence.** A package that breaks this rule is refused when it is proposed, and a version
  found to break it later is blocked: the launcher stops installing it, and turns it off on a
  player's machine at the first start after that machine has read the catalog naming the block.

## Reaching us

Rights holders, and anyone who finds a package that breaks this rule, reach the maintainers through
<https://azreborn.com/contact>. Please name the package, its version and the file.
